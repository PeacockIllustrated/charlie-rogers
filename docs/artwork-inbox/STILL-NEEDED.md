# Still needed from the mailbox

A shopping list for one pass through Outlook. Everything here is catalogued in
`manifest.json` (89 attachments across 41 messages in the `Charlie Rodgers`
folder, note the spelling) and is **not** on disk in this repository.

Work down the list in order. The top section blocks a page or a product that is
live now; the lower sections are archive material that improves pages rather
than unblocking them.

## How to find things

Brian sends from an iPhone, so almost every image arrives named `image.png`,
`Image-1.jpg` or `Image.jpeg`, and several attachments in the same message share
one name. The only reliable handle is the **byte size**, given below for each
item. Outlook shows it in the attachment list, or on hover. Where a message
holds several images, the count is stated so you know when you have them all.

Save downloads into `artwork-masters/` if they are paintings, and regenerate the
1600px derivatives in `public/artwork/web/` afterwards; anything else can go
wherever the page that uses it needs it. Nothing in `artwork-masters/` is served
to a browser, which is deliberate. See `artwork-masters/README.md`.
